# IoTDemos
Repositório com algoritmos da disciplina de Programação para IoT. Este repositório está organizado em capítulos, assim como a disciplina, porém apenas capítulos que possuem exemplos práticos estão listados. Importante pontuar que é possível encontrar códigos de exemplo tanto em micropython como em C++ (Arduino).

1. Capítulo 2 - Ferramentas Práticas
2. Capítulo 3 - Protocolos de transmissão de dados
3. Capítulo 4 - Tecnologias de Rede
4. Capitulo 5 - Protocolos de Comunicação
5. Capítulo 6 - Infraapps
6. Capítulo 7 - Segurança e Privacidade de Dados

## Capítulo 2 - Ferramentas Práticas

Neste capítulo são apresentadas as ferramentas práticas Bipes, Wokwi, Visual Studio, Tonny, Arduino IDE, etc., que são usadas no decorrer do curso.

## Capítulo 3 - Protocolos de Transmissão de Dados

Neste capítulo são apresentados os principais protocolos usados para comunicação entre microcontroladores e periféricos, como o SPI, I2C e UART. 

## Capítulo 4 - Tecnologias de Redes

Neste capítulo são apresentadas a principais tecnologias de redes usadas em soluções IoT, como ethernet, wifi, Bluetooth Clássico, BLE, Redes Móveis, Sigfox, Lora, NFC, Zigbee, etc.

## Capítulo 5 - Protocolos de Comunicação

Neste capítulo são apresentados os principais protocolos de comunicação usados em soluções IoT: HTTP, CoAP, AMQP e MQTT.

## Capítulo 6 - Infraapps

Neste capítulo são apresentados serviços que estruturam um solução IoT, como Grafana, InfluxDB e Mosquitto, além de utilizar o Docker para estruturação de uma infraestrutura de aplicação.

## Capitulo 7 - Segurança e Privacidade de Dados

Neste capítulo tratamos dos mecanismos de segurança de dados nas diferentes camandas de um solução IoT.
